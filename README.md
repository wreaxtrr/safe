# Сейф

Прототип безопасной сделки с рук на цифровом рубле. Делаем для Академии Финтеха 2026 (трек «Финтех без границ»), команда ClaimToFame.

Идея: покупатель резервирует деньги, продавец видит, что они реально есть, и получает их только по коду покупателя после передачи товара. Если сделка не состоялась, деньги возвращаются покупателю.

## Запуск

Открыть `index.html` в браузере, ничего ставить не нужно.

## Что можно потыкать

- создать сделку за продавца
- зарезервировать деньги за покупателя
- показать код и ввести его у продавца — деньги уйдут продавцу
- нажать «+24 часа» после резерва — сработает автовозврат
- отказаться от покупки и открыть спор

## Что пока не настоящее

Кошельки, цифровой рубль и смарт-контракт эмулируются прямо в браузере, данные хранятся в localStorage. Сервера пока нет.
