# Сейф — сервис безопасных P2P-сделок

**Сейф** — веб-приложение для безопасного проведения сделок между частными лицами. Сервис моделирует процесс резервирования средств, подтверждения получения товара и завершения сделки. Его основная задача — снизить риск ситуации, когда одна сторона выполнила свои обязательства, а другая отказалась от сделки.

Проект разработан в рамках **Fintech Academy 2026**.

**[Открыть демо →](https://safe-9cx6.onrender.com/)**
> **Важно:** «Сейф» — демонстрационный прототип. Все денежные операции выполняются с использованием виртуальных балансов. Реальные платежи и переводы денежных средств не осуществляются.

## Возможности

- Создание сделок продавцом с указанием названия, описания и стоимости товара.
- Просмотр доступных сделок и их бронирование покупателем.
- Резервирование виртуальных средств на время сделки.
- Подтверждение получения товара с помощью уникального шестизначного кода.
- Автоматический возврат средств при истечении срока сделки.
- Отмена сделки и обработка запросов на возврат.
- Открытие споров при возникновении разногласий.
- Административное разрешение спорных ситуаций.
- История событий, связанных со сделкой.

## Как работает сервис

### 1. Создание сделки

Продавец создаёт сделку, указывая информацию о товаре и его стоимость. Для сделки можно выбрать срок подтверждения: 24, 48 или 72 часа.

### 2. Бронирование

Покупатель выбирает доступную сделку и резервирует её. Необходимая сумма списывается с его виртуального доступного баланса и удерживается до завершения сделки.

После бронирования покупатель получает уникальный шестизначный код подтверждения.

### 3. Подтверждение получения

После получения товара покупатель передаёт код продавцу. Продавец вводит его в интерфейсе приложения.

Если код верный, сделка завершается, а зарезервированные средства переводятся на виртуальный баланс продавца.

### 4. Возврат или спор

Если покупатель отказывается от сделки, продавец может согласиться на возврат средств либо открыть спор.

Если стороны не могут договориться, спор передаётся администратору, который принимает решение.

Если срок сделки истекает, а получение товара не подтверждено, система автоматически возвращает средства покупателю.

## Статусы сделки

| Статус | Описание |
|---|---|
| `open` | Сделка создана и доступна для бронирования |
| `reserved` | Сделка забронирована, средства зарезервированы |
| `completed` | Сделка успешно завершена |
| `cancelled` | Сделка отменена |
| `dispute` | По сделке открыт спор |
| `refunded` | Средства возвращены покупателю |
